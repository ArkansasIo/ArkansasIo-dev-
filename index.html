CURRENT PROJECT

Life Engine Rust

A clean-room artificial-life simulation that combines cellular organisms, genome evolution, neural decisions, ecology, and replayable runs in one Rust project.

⌘

Life Engine Rust

Rust · CLI

Run seeded simulations from the terminal, inspect population statistics, and export results for further analysis. Rendering remains separate from the simulation core.

CAPABILITIES

Designed for experimentation

Core systems are modular, seeded, and testable, keeping experiments easier to reproduce and extend.

01

Evolution

Genome mutation, crossover, parent tracking, and generation-aware selection.

02

Neural behaviour

Seeded neural controllers support exploring, seeking food, fleeing threats, mating, and attacking.

03

Ecology & physics

Model environmental resources and basic particle physics alongside organism needs.

04

Replay & statistics

Reproduce seeded runs and export CSV or JSON summaries for inspection.

GET STARTED

Run a simulation

Install the stable Rust toolchain, clone the repository, and run a repeatable sample.

SHELL
git clone https://github.com/ArkansasIo/ArkansasIo-dev-.git
cd ArkansasIo-dev-/life-engine-rust
cargo run --release -- --seed 1234 --population 100 --ticks 1000
Verify before you extend

Run formatting, lint, tests, and the release build from the project directory.

Read the test guide ↗
cargo fmt --all -- --check
cargo clippy --all-targets --all-features -- -D warnings
cargo test --all
cargo build --release
